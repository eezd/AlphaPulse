## 离线运行

在项目根目录使用已经安装项目依赖的后端虚拟环境：

```bash
cd /srv/AlphaPulse
backend/.venv/bin/python scripts/briefing_quality.py runtime/quality/analysis-v3-20261114
```

工具只读取本地文件并向标准输出打印JSON，不连接数据库、Redis、模型或TG。它核对基线摘要、样本配额、输入和规则摘要、来源修订、时间锚点及标注引文，然后调用生产共用的结构和逐字证据校验器。校验失败会明确报错，不自动修改样本或补齐结果。

本次实际核验：100条配额及来源绑定通过；旧结果60条结构/引文通过、40条失败；4条超长均为明确未发送；96个已记录调用合计输入841,968、输出180,661，共1,022,629 Token。这只是固定集原有调用的用量，本轮离线核验未产生模型用量。原记录没有可靠的逐请求耗时，报告为未知。

当前没有完整填写旧结果的逐条语义评审，也没有v3候选输出。报告中的 `semantic.complete: false` 和未评审计数是预期状态，不能将60条契约通过称为事实准确率，更不能据此宣布v3改善。

## 后续结果文件协议

真实模型回跑及历史重算须另获对应授权；本次v3发布不包含这些操作。获准回跑后，保持100条输入及上述模型参数完全一致，唯一比较变量是Skill内容。基线没有保留当年失败时被拒绝的完整候选输出；这些案例只能比较已有错误类别与新一轮结果，不能复原当时的具体错误文本。

候选JSON顶层包含：

- `baseline_sha256`：固定基线摘要。
- `model_config`：基线报告中的完整同名对象，含provider_id，不能只保持模型名而改变上下文或推理强度。
- `skill_sha256`：实际使用的UTF-8草稿文件字节SHA256，64位小写十六进制；调用时冻结同一内容。
- `cases`：全部100条结果，使用基线中的整数 `id` 和 `input_sha256`，不得漏项或重复。

每条结果包含 `id`、`input_sha256`、`state`（`done`/`failed`/`blocked`）、`output`、`usage`、`not_sent`，可选 `elapsed_seconds`。成功输出须是完整 `NewsAnalysisResult`，失败或阻塞的 `output` 为null。`usage` 采用现有input_tokens/output_tokens或rounds结构；缺失用量标未知。只有实际未发送的结果才能填 `not_sent: true`，同时usage必须为null；4条超长样本须保持发送前阻塞，不能靠截断原文或改变参数获得成功。耗时记录完整请求与有限修复的实际时间，不混入排队时间；缺失填null，不补造。

工具会输出结构/引文错误位置、各分层状态、超长准入违规ID、用量及耗时覆盖，不读取候选文件声明的新闻内容替换基线输入。输入和参数摘要属于结果生产者的来源声明，工具本身不能证明外部调用确实使用了这些内容；实际回跑还须保留对应请求审计材料。

```bash
backend/.venv/bin/python scripts/briefing_quality.py runtime/quality/analysis-v3-20261114 \
  --candidate runtime/quality/analysis-v3-20261114/candidate.json
```

人工语义评审JSON通过 `baseline_sha256`、`gold_sha256` 和 `candidate_sha256` 绑定输入、标注和候选文件；只评旧基线时candidate_sha256为null。顶层 `baseline`、`candidate` 各为评审列表。每项含整数 `id`、`checks`（该案例全部标注检查ID到 `pass`/`fail`/`uncertain` 的映射）、布尔值 `critical_error` 及非空 `notes`。失败结果没有成功输出，不填语义评审；4条超长只评准入，不填语义评审。缺评审和不确定项均不能计为通过；全部失败也不会被标为评审完成。

```bash
backend/.venv/bin/python scripts/briefing_quality.py runtime/quality/analysis-v3-20261114 \
  --candidate runtime/quality/analysis-v3-20261114/candidate.json \
  --reviews runtime/quality/analysis-v3-20261114/reviews.json
```

后续验收按同一检查点比较：新增重大事实错误为零、关键事实覆盖不下降、证据完整可追溯、实体表达更一致、失败率下降，并同时查看Token与耗时成本。工具提供诊断和评审计数，不自动判定“质量提升”或推断全量准确率。
